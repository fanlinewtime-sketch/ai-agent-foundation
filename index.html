What TokenWarden does

Meter everything. Enforce what you set.

FAQ

Questions developers ask

Which providers and frameworks are supported?

Any OpenAI-compatible API — OpenAI, Azure, Bedrock, and friends. You change the base_url; your code stays the same. LangChain, LlamaIndex, CrewAI, and raw SDKs all work out of the box.

What do you do with my request data?

TLS end-to-end. We meter token counts and metadata by default; request payloads pass through and are not stored. An opt-in PII-aware mode is on the roadmap — mention it on the waitlist form if you need it early.

How is this different from LiteLLM, Helicone, or Portkey?

LiteLLM is a proxy library with basic key-level caps. Helicone is observability — it shows the burn. Portkey adds routing. TokenWarden combines per-agent/per-customer attribution, hard enforcement, and alerting in one product built for small teams, not a platform you'll outgrow or an OSS project you maintain yourself.

When does it launch?

We're building in public now. Waitlist members get first access and the early-bird price locked. First-cohort access is planned within weeks of the waitlist closing.

Can I self-host it?

Cloud first. Self-hosting is on the roadmap — tell us on the waitlist form if it's a requirement; it shapes what we build first.
